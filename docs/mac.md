# Mac

Im Projektordner doppelklicken:

- `Aether starten.command` — Server an, Browser auf
- `Aether stoppen.command` — Server aus
- `Aether updaten.command` — `git pull` und `npm install`

Beim ersten Mal: Rechtsklick → Öffnen, falls macOS die Datei blockiert.

Ohne npm: Node von [nodejs.org](https://nodejs.org) holen, danach erneut starten.

Immer [http://127.0.0.1:45217](http://127.0.0.1:45217) nutzen, nicht `localhost` — sonst liegen die Speicherstände woanders.
